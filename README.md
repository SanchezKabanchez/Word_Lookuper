# Word Lookup 8.5

Український словник поверх гри: OCR, вибір слова стрілками, переклад, бібліотека та Anki.
Для ігор використовуй **«Вікно без рамки» / Borderless**.

## Запуск на Windows

1. Розпакуй архів в окрему папку. Встанови **Python 3.11–3.13 x64** з Tcl/Tk та Python Launcher.
2. Запусти **`install.bat`**. Він створить `.venv`, поставить закріплені залежності та RapidOCR разом із моделями.
3. Запусти **`start.bat`**. У налаштуваннях можна ввести й окремо зберегти ключ DeepL.

Збірка **Windows EXE** не потребує Python: розпакуй увесь каталог `WordLookup` і запусти `WordLookup.exe`.
EXE створює [workflow збірки](.github/workflows/build-windows.yml); результат — артефакт відповідного
прогону, а для тегів `v<версія>` — файл релізу. Наявність готової збірки перевіряй за результатом CI.
Архів із вихідним кодом та EXE — різні завантаження.

**Оновлення:** закрий програму, розпакуй нову версію в нову папку й повтори встановлення.
Бібліотека та ключі зберігаються окремо від програми; файли з даними замінювати не потрібно.
Другий запуск активує перше вікно замість створення другої копії з такими самими біндами.

## Вибір слова

- **Ctrl+Alt+R** — знімок активного екрана; стрілки переміщують вибір між словами й рядками,
  **Enter** відкриває картку, **Esc** закриває накладку.
- **Ctrl+Alt+D** — слово під курсором; **Ctrl+Alt+L** — переклад рядка, якщо цей бінд не змінено в налаштуваннях.
- Заголовок картки можна виправити мишею або через **Tab → Enter/Пробіл**.
- **Ctrl+Enter** у картці зберігає слово. Бібліотека має список, пошук, редактор, повторення та експорт.
- Колесо миші прокручує вкладку/картку під курсором; на краю поля прокрутка переходить до сторінки.

Стоп-кадр заморожує **зображення**, а не гру. Призупинення процесу — окрема опція, вимкнена за замовчуванням.
Вона може впливати на рушій гри, звук і FPS навіть після відновлення. Використовуй лише в несуттєвій
одиночній грі; в онлайні не вмикай. Сторож відновлює процес після збою Word Lookup, але не відновлює
внутрішній стан рушія. Для проблеми з FPS у Mafia є [інструкція вимірювання](docs/PERFORMANCE.md).

## Переклад і приватність

У вкладці словника можна дозволити кожне мережеве джерело, обрати «лише DeepL» або вимкнути мережу.
Слово та контекст отримують лише дозволені джерела. На картці показано, яке джерело дало переклад.

- **DeepL** — офіційний API, має пріоритет за наявності ключа.
- **Google Cloud Translation** — офіційний Basic v2 API, потребує ключа, увімкненого API та білінгу Google.
- **LibreTranslate** — власний сервер або API; HTTPS, або HTTP лише на localhost/loopback.
- **Google GTX/Chrome/mobile** — неофіційні адаптери; формат, доступність і умови використання сервісу
  можуть змінитись. Контрактні тести перевіряють відомі формати, але не гарантують доступності Google.
- **MyMemory**, dictionaryapi.dev, Datamuse — окремі дозволи; MyMemory можна повністю вимкнути.

Ключі не записуються у `config.json`: Windows використовує Credential Manager або DPAPI, macOS — Keychain,
Linux — Secret Service за наявності DBus і розблокованого сховища. Якщо захищене сховище недоступне,
ключ працює лише в поточному сеансі, а програма показує це явно. Звичайні зміни налаштувань
не повторюють невдалий запис ключа; для повтору є **«Зберегти ключ»**.

### Необов'язковий офлайн-перекладач

Для **версії з Python** запусти `install_offline.bat`, завантаж потрібну SentencePiece-модель з
[офіційного каталогу Argos](https://www.argosopentech.com/argospm/index/) і вибери
**«Імпортувати .argosmodel…»** у налаштуваннях. Увімкни локальний рушій; для роботи без мережі
вибери офлайн-режим. Модель має підтримувати `English → обрана мова` та містити `sentencepiece.model` (BPE-моделі відхиляються з поясненням).

Моделі встановлюються лише явно, без автоматичного завантаження. Argos працює на CPU, за замовчуванням
із двома потоками, і потребує додаткової пам'яті та місця. В EXE рушій CTranslate2/SentencePiece уже включено, але мовні моделі потрібно імпортувати окремо.
Torch, Stanza та spaCy не встановлюються. Встановлення доповнення через pip стосується Python-версії. Без моделі залишаються локальна бібліотека,
кеш і частотний словник, а програма повідомляє про відсутність локального перекладу.

Частотність 50 000 англійських слів — **не CEFR**. Походження, SHA-256 і окрема ліцензія **CC BY-SA 4.0**:
[wordlookup/data/README.md](wordlookup/data/README.md).

## Дані та відновлення

- Windows: `%APPDATA%\WordLookup`
- macOS: `~/Library/Application Support/WordLookup`
- Linux: `$XDG_CONFIG_HOME/WordLookup` або `~/.config/WordLookup`

`WORD_LOOKUP_DATA_DIR` явно задає інший профіль. Не використовуй його випадково при оновленні:
інша папка означає іншу бібліотеку. `saved_words.json` містить слова й прогрес; п'ять останніх
резервних копій створюються перед змінами. Для відновлення є **«Відновити з файлу…»** в бібліотеці.
Старі списки JSON читаються автоматично; нові записи мають версію схеми. Файли з новішою невідомою
схемою не перезаписуються. Пошкоджений конфіг зберігається як `config.json.corrupt…`.

У вкладці діагностики можна очистити журнал або зберегти **локальний ZIP** зі звітом, версіями,
DPI й обмеженою часовою шкалою. Запис діагностики та додавання знімка OCR вимикаються окремо й
типово вимкнені. Знімок може містити приватний текст. Журнал містить шукані слова; перед передаванням
пакета переглянь його. Програма нічого не надсилає разом із натисканням кнопки експорту.

## Linux / macOS і розробка

Linux: встанови `python3-tk`, `xclip`, один OCR-рушій; macOS: Python із Tk та дозволи Accessibility / Screen Recording.

```sh
python3 -m venv .venv
# Windows: .venv\Scripts\activate; Linux/macOS:
. .venv/bin/activate
python -m pip install -r requirements-ocr.txt -c requirements.lock
python scripts/compile_translations.py
python word_lookup_launcher.py
```

Перевірки, відтворення lock-файлів, збірка EXE та локалізація описані в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
Python 3.10 більше не підтримується через вразливу останню сумісну гілку Pillow.
Інсталятор зберігає старе несумісне `.venv` під іншою назвою й створює нове; навчальні дані лишаються в каталозі профілю.
Python 3.14 поки не підтримується: у закріпленого `pygame==2.6.1` немає Windows-wheel `cp314`
(перевірено 17.11.2026). Підтримка переглядатиметься після оновлення й перевірки залежностей.
