# Word Lookup v8 — менше CPU й пауза біндів

[Завантажити ZIP](./Word_Lookuper-v8.zip?raw=true)

OCR обмежено двома потоками за замовчуванням, без активного очікування ONNX і паралельних нативних проходів. Розпізнаний кадр і контекст повторно використовуються; додано кеш наведення та скасування. Виправлено гарячий цикл очікування кешу після TimeoutError.

Прямий бінд слова/рядка та кнопка миші тепер запускають підтверджену паузу, якщо її ввімкнено в налаштуваннях/профілі. Режим до закриття картки / Esc утримує паузу до завершення або ліміту. Реальна Mafia та Windows у цій сесії не перевірені.

Після розпакування: install.bat, потім start.bat. На «Головна» увімкнути «Призупиняти активну гру при OCR-пошуку», вибрати «До закриття картки / Esc (з лімітом)». Профіль гри має пріоритет над загальним перемикачем. У «Словник і OCR» можна встановити 1 потік для слабшого ПК.

311 тестів пройшли на Linux/Xvfb, 1 пропущено. Реальні RapidOCR і Tesseract перевірені на синтетичних зображеннях. Повний звіт і відтворюваний benchmark — усередині ZIP. PNG/XML/сирі вимірювання в архів не включено.
