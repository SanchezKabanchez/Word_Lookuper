Бібліотека перечитується при відкритті. Кнопка «Оновити» також скидає фільтри. Вікно показує фактичний шлях до saved_words.json і повідомляє про помилки читання.

«Відновити з файлу…» додає відсутні слова зі saved_words.json або резервної копії, зберігаючи поточні правки й прогрес. Перед зміною наявного файла створюється його точна копія в saved_words.recovery. Виявлений застарілий запис після зовнішньої зміни файла блокується.

Перед запуском закрий старі копії через значок у треї. Розпакуй архів і запусти start.bat; для нового встановлення спочатку install.bat. Відкрий Бібліотеку → Оновити. За потреби вибери свій JSON через «Відновити з файлу…».
