# Word Lookup 8.4

[Скачати Word_Lookuper-v8.4.zip](./Word_Lookuper-v8.4.zip?raw=true)

Список слів і картка у бібліотеці мають мінімальну ширину: панелі більше не згортаються до нуля. Натисни слово зліва для деталей, двічі натисни або натисни Enter для картки.

Колесо прокручує видиму область під курсором на всіх чотирьох вкладках, у тому числі над кнопками й полями. Значення числових полів і закритих випадаючих списків не змінюються. Список бібліотеки й деталі прокручуються окремо; довгий текст прокручується спочатку всередині свого поля.

Закрий стару копію програми через значок у треї, розпакуй архів і запусти start.bat. Для першого встановлення спочатку install.bat. Дані бібліотеки залишаються у каталозі налаштувань.
