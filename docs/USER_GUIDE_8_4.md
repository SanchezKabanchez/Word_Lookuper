# Word Lookup

Український словник і перекладач поверх гри, браузера чи PDF. Продовження надісланого `word_lookup.py`: збережені OCR, переклад рядка/області, DeepL, озвучення, гарячі клавіші та Anki.

## Видимий список слів і колесо миші (оновлення 8.4)

У бібліотеці список слів зліва більше не можна згорнути до нульової ширини. Обидві панелі мають мінімальну ширину з урахуванням шрифту; початкова позиція розділювача задається після появи вікна. Натисни слово в списку, щоб побачити його деталі праворуч. Подвійне натискання або Enter відкриває картку; стрілки в списку переходять між словами.

Колесо працює на всіх чотирьох вкладках налаштувань, навіть над текстом, кнопками, прапорцями та полями. Воно прокручує видиму область під курсором і не змінює значення закритих випадаючих списків чи числових полів. Довге текстове поле спочатку прокручує свій текст, а на межі передає прокручування сторінці. У бібліотеці список і деталі слова прокручуються незалежно. Фонових потоків або постійного опитування для цього не додано.

## Бібліотека після оновлення (оновлення 8.3)

Бібліотека перечитується при відкритті. **Оновити** також скидає пошук, фільтр стану й «Час повторити», щоб приховані записи знову з'явилися. У вікні показано кількість видимих і загальних слів та фактичний шлях до файла. У Windows типовий шлях — `%APPDATA%\WordLookup\saved_words.json`; розпакування нової версії не має переносити ці дані.

Якщо маєш збережений `saved_words.json` або резервну копію, натисни **Відновити з файлу…** й вибери її. Додаються лише відсутні слова; поточні правки та прогрес наявних записів зберігаються. Перед зміною наявного файла його точна копія записується в `saved_words.recovery` поряд із ним. Звичайні п'ять резервних копій залишаються в `saved_words.backups`. Сам файл, вибраний для відновлення, не змінюється.

Пошкоджений або недоступний файл тепер має видиму помилку й не замінюється порожнім списком. Підтримується UTF-8 із BOM. Якщо виявлено зміну файла іншою копією програми, запис зі старого кешу блокується до перечитування. Перед переходом на нову версію закрий попередню через значок у треї. Пошуки використовують кеш у пам'яті: постійного опитування файла не додано.

## Збереження ключа DeepL (оновлення 8.2)

Введи ключ у налаштуваннях і натисни **Зберегти ключ**. Програма перевіряє збережене значення читанням зі сховища; після наступного запуску ключ підставляється автоматично. Якщо Windows Credential Manager відмовляє, використовується файл `%APPDATA%\WordLookup\deepl-key.dpapi`, зашифрований Windows DPAPI для поточного облікового запису. Статус показує, яке сховище спрацювало. Якщо обидва способи недоступні, програма прямо повідомляє, що ключ працює лише в поточному сеансі.

Файл DPAPI має пріоритет над старим записом Credential Manager. Під час очищення ключа недоступний старий запис блокується зашифрованою порожньою позначкою, щоб не повернутися при наступному запуску. Цей файл не призначений для перенесення ключа на інший комп'ютер або обліковий запис. Ключ не потрапляє в JSON чи журнал. Звичайні перемикачі не запускають повторного збереження ключа.

## Вибір слова й автозбереження (оновлення 8.1)

OCR тепер використовує позиції символів розпізнавача для меж слів замість вгадування пропорцій. Клік приймає слово лише в його фактичній рамці; застаріле наведення, сусідня рамка та проміжок між словами не підміняють вибір. Уточнення фрагмента з кількох слів теж перевіряє точку курсора. На справжньому RapidOCR перевірено `Official`, `Main`, `Menu` у 18 варіантах жирного заголовка з масштабами шрифту 100/125/150% та від'ємним початком монітора. Це синтетична перевірка геометрії, а не підтвердження реального Windows DPI чи точного знімка користувача.

Звичайні перемикачі, зокрема **Підсвічувати слово під курсором**, більше не читають і не записують Windows Credential Manager. Ключ DeepL записується лише після зміни самого ключа або явного натискання **Зберегти ключ**; незмінний невдалий запис не повторюється при кожному збереженні. Невдале видалення ключа теж має видимий статус. Ключ ніколи не потрапляє в JSON чи журнал.

Після зміни мови поточний пошук скасовується, а попередні переклади залишаються в кеші за своєю мовою. Відкриття прикладу або бібліотечної картки також скасовує застарілий живий запит, щоб пізня відповідь не замінила вибрану картку. Збереження ключів і регресії вибору слова перевіряються окремими тестами. Очищення кешу не дозволяє старим фоновим відповідям наповнити його знову. Після тайм-ауту запиту зупиняються подальші резервні спроби; уже надісланий HTTP-запит завершується сам.

Бібліотека зберігає лише змінені користувачем поля, тому фонове визначення чи стан повторення не втрачаються. Відкинута чернетка перечитується зі збережених даних. Дозаповнення та експорт працюють з узгодженими копіями, а запис бібліотеки й перенесення завершених оновлень серіалізовані: пізній робочий потік не замінює ручні правки, видалені записи чи дані після тайм-ауту.

## Менше навантаження й пауза для бінда слова (версія 8)

Прямий пошук слова **Ctrl+Alt+D** і пошук кнопкою миші раніше обходили механізм паузи. Тепер пошук слова/рядка, вибір області та керований курсор використовують одну перевірену паузу активного процесу. Копіювання виділеного тексту з браузера не призупиняє програму.

**Mafia: The Old Country:** користувач повідомив про стійке падіння FPS навіть після одного призупинення, до перезапуску гри. Для цієї гри залишай паузу процесу вимкненою і глобально, і в її профілі. Стоп-кадр і вибір слова працюють без призупинення; гра на фоні продовжує працювати. Причину в рендерері/драйвері не підтверджено, виправлення FPS не заявляється.

Для інших одиночних ігор режим **До закриття картки / Esc (з лімітом)** доступний після власної перевірки сумісності. Якщо є профіль гри, його перемикач паузи має пріоритет над загальним. Закриття картки, Esc, аварійний бінд **Ctrl+Alt+P**, помилка, вихід чи сторож відновлюють процес. Запізнілий OCR не починає паузу заново. Нове встановлення має ліміт **60 с**; раніше збережений ліміт, зокрема 20 с, зберігається. Його можна змінити в налаштуваннях.

Режим **Лише для захоплення кадру** зберігає попередню коротку паузу. Сам перемикач паузи лишається вимкненим за замовчуванням. Якщо автовизначення відмовляє, використай **Перевірити визначення через 3 с** й перемкнись у гру; за потреби введи точний `.exe` із вкладки «Подробиці» Диспетчера завдань. При `AccessDenied` перевір, чи гра запущена з підвищеними правами; програма не обходить захист процесу. Назву процесу Mafia не вгадано й не підмінено назвою лаунчера.

Для OCR початково виділено **2 потоки CPU**; можна вибрати 1–4 на вкладці «Словник і OCR» → «Навантаження OCR». ONNX працює без активного очікування, OpenCV обмежений тим самим числом потоків, Tesseract має локальний ліміт OpenMP і тайм-аут. Один нативний OCR виконується за раз. Це ліміт паралельності, а не гарантія певного відсотка CPU всього ПК.

Вибір захоплює лише активний монітор; наведення має затримку 250 мс, кеш того самого кадру та об'єднання зайвих запитів. Розпізнаний кадр повторно використовується для речення. Esc/закриття скасовують очікування та наступні спроби; уже запущений нативний прохід завершується сам (Tesseract також обмежений тайм-аутом). Максимальна сторона OCR-знімка початково 1600 px; зменшення економить ресурси, але може погіршити читабельність дрібного тексту — за потреби збільш цей параметр.

Приховані словникові блоки більше не запускають зайвого запиту за визначенням, якщо також вимкнені транскрипція й озвучення. Повторний кешований переклад не запускає новий OCR речення без потреби. Усунуто гарячий цикл очікування кешу при помилці тайм-ауту; незмінені часткові результати не перебудовують картку. У простої головне вікно перевіряє події рідше, а під час взаємодії залишається швидким.

На скриншоті Диспетчера завдань загальні 100% CPU і 86% GPU не показують частку Word Lookup. Для точного порівняння дивись окремо процес гри та `python.exe`/Word Lookup на вкладці «Процеси». Пауза лишається призупиненням процесу: спершу тестуй на несуттєвій одиночній грі й не вмикай її в онлайні. Реальна Mafia у Windows у цій хмарі не запускалась.

## Читабельність накладок і компактна картка (версія 7)

Вибране на стоп-кадрі слово позначається суцільною рамкою 2 px і підкресленням, без заливки поверх літер. Верхня підказка має темне тло, відступи та перенесення; її видно й на світлій сцені. Така сама плашка є у керованого курсора.

У бібліотеці фільтри мають власне темне оформлення, смуги прокрутки узгоджені з ним. Для гри виділено ширшу колонку й горизонтальну прокрутку; повне джерело вибраного слова показується окремо з перенесенням.

Для нового встановлення картка має ширину 400 px і шрифт 10 pt, показує один головний переклад та одне визначення. Приклади, тезаурус, додаткові переклади й зображення початково приховані. Їх можна повернути окремими перемикачами або пресетом **Докладна**. Синоніми в докладному вигляді — чипи, англійське визначення та його переклад візуально різняться.

**Оновлення не переписує збережені налаштування.** Щоб застосувати новий типовий вигляд до вже встановленої програми, відкрий «Картка перекладу» → **Збалансована**; для ще коротшої картки вибери **Компактна**.

PNG і XML результатів більше не входять у вихідний ZIP/репозиторій: вони створюються під час перевірки й передаються як артефакти GitHub Actions. Windows-CI має окремі знімки Segoe UI при масштабах Tk 100%, 125% і 150%. Маніфест фіксує запитаний і фактичний масштаб; це перевірка верстки шрифту, а не зміна апаратного DPI дисплея чи запуск накладки поверх гри.

## Оновлення за перевіркою коду

- **Вибір без миші:** `Ctrl+Alt+R` створює стоп-кадр, розпізнає його один раз і підсвічує перше слово. `←/→` переходять між словами, `↑/↓` — між рядками, `Enter` відкриває картку, `Esc` скасовує. Вибір **Наведення мишею** повертає попередню поведінку. Клавіатурний режим не намагається відкріпити курсор гри.
- **Профілі ігор:** на «Головна» можна додати точну назву `.exe`, спосіб вибору, розміри OCR, паузу й тег Anki. Профіль застосовується до активного вікна, з перевіркою процесу; фонова гра не вибирається. Параметри фіксуються для конкретного пошуку й не змінюють загальні налаштування. Тег профілю зберігається разом із карткою та має пріоритет над загальним тегом Anki. Новий профіль має вимкнену паузу.
- **Мережеві джерела:** у «Словник і OCR» є окремі перемикачі Google, MyMemory, Datamuse, dictionaryapi.dev та DeepL і кнопки **Усі джерела / Лише DeepL / Лише локально**. DeepL також потребує ключа й власного перемикача. Офлайн працюють бібліотека, кеш, локальні форми та виправлення OCR; нових перекладів частотний файл не містить. Аудіо за URL і діагностика теж дотримуються дозволів. Місцевий AnkiConnect доступний офлайн. Уже надісланий запит не можна відкликати.
- **Локальна частотність:** 50 000 англійських слів, близько 623 КБ. Біля заголовка показується частотність у корпусі субтитрів. Це **не CEFR / B2**. Походження, незмінений файл та повна ліцензія **CC BY-SA 4.0** — у [data/README.md](../wordlookup/data/README.md). Виправлення обережні, наприклад `changin → changing`; власні назви й незнайомі слова можна виправити вручну. Ручне введення більше не переписується автоматичним виправленням.
- **Резервні копії:** попередні п'ять версій `saved_words.json` зберігаються поруч у `saved_words.backups/`; пов'язані з ними зображення зберігаються до ротації. Для відновлення закрий програму, збережи поточний файл окремо та скопіюй потрібну резервну версію як `saved_words.json`. Помилка резервування зупиняє запис, а пошкоджений поточний JSON не перезаписується.
- **Anki:** стандартний шаблон містить `{{tts en_US:Word}}`; голос забезпечує Anki/операційна система, звукові файли програма не створює. Власний змінений шаблон не перезаписується.
- **Журнал:** кнопка **Очистити журнал** видаляє поточний файл і ротацію. Перед копіюванням звіту є попередження про слова й фрагменти тексту; ключі маскуються.
- **Перевірки:** тести паузи очікують фактичного стану процесу з повторами та монотонним таймаутом. CI зберігає PNG справжніх вікон картки, бібліотеки та накладок, побудованих із локальних тестових даних.

Пауза лишається призупиненням процесу, а не внутрішньою паузою гри. Режим «Лише для захоплення кадру» відновлює процес одразу після знімка; режим до закриття картки утримує паузу до закриття/Esc або ліміту. Спершу перевір на несуттєвій одиночній грі; **не вмикай в онлайні**. Наявність сторожа не доводить сумісності з Cyberpunk чи Indiana Jones.

## Компактний інтерфейс і власна картка (версія 5)

На вкладці **Картка перекладу** можна змінити шрифт, ширину, тему, прозорість і час показу. Типовий шрифт зменшено до **10 pt**, головний переклад більше не має надмірного збільшення. Є готові варіанти **Компактна**, **Збалансована** та **Докладна**. Налаштування одразу застосовуються до відкритої картки зі збереженням закріплення й прокручування.

Окремі перемикачі керують перекладом слова, оригіналом речення, перекладом речення, транскрипцією, визначеннями, перекладом визначення, прикладами, синонімами й антонімами, додатковими перекладами, зображенням і кнопками озвучення. Переклад речення можна приховати, залишивши оригінал, або навпаки. Приклади та переклад визначення належать до блоку визначень. У картці перекладеної фрази основний переклад залишається видимим; перемикач речення ховає її оригінал.

Меню **Вигляд ▾** доступне безпосередньо в картці. Відкриття цього меню закріплює картку, щоб вибір пунктів її не закрив; **Відкріпити** повертає звичайну поведінку. Приховування блоку не видаляє даних із бібліотеки та експорту. Сам текст збереженої картки редагується в **Бібліотеці**, **Ctrl+S** зберігає правки; англійське визначення та його переклад редагуються незалежно.

Переклад слова й словник тепер запитуються паралельно, а перший результат показується без очікування словника. Вимкнений переклад речення чи визначення не створює відповідного додаткового запиту. Скасований пошук не починає наступний етап OCR/перекладу; запит, який уже відправлено, може завершитися у фоні. Резервний мобільний перекладач має явний мережевий тайм-аут 8 секунд. Серія змін повзунків і полів зберігається одним записом після 300 мс спокою, а вихід зберігає відкладені зміни.

Старі налаштування читаються автоматично: попередній типовий шрифт 12 pt стає 10 pt, інші розміри зберігаються; вимкнене раніше речення залишається вимкненим разом із його перекладом. Перевірки в Linux охоплюють справжні вікна Tk, меню, незалежність перемикачів, збереження, скасування та паралельне завантаження з контрольованими джерелами. Це не вимірювання FPS чи затримки у Windows-грі та не перевірка доступності зовнішніх перекладачів.

## Автоматичне визначення активної гри (версія 4, Windows)

Вручну вводити `.exe` зазвичай більше не потрібно. На «Головна» увімкни **Призупиняти активну гру при OCR-пошуку** та залиш увімкненим **Автоматично визначати активну гру**. Повернись у гру й натисни **Ctrl+Alt+R** або **Ctrl+Alt+G**. Програма визначає PID саме активного вікна при натисканні, а не вибирає довільну запущену гру у фоні. Якщо ти перейшов у браузер, фонову гру вона не призупиняє.

Для перевірки без паузи є кнопка **Перевірити визначення через 3 с**: натисни її й перемкнись у гру. Після перевірки в налаштуваннях з'явиться назва вікна, процес і причина розпізнавання. Ця кнопка лише читає дані, не призупиняє процес.

Автовизначення використовує локальні позначки Windows Game Mode, типові каталоги Steam/Epic/GOG/Xbox/EA/Ubisoft/Rockstar, назви відомих ігор та ознаку Unreal Engine Shipping. Це евристика, а не універсальний каталог усіх ігор. Самого повноекранного вікна недостатньо. Браузери, поширені системні процеси, редактори, лаунчери та обробники збоїв виключені. Після визначення ще раз перевіряється, чи активне вікно не змінилося; сторож паузи далі перевіряє PID і час створення.

Якщо даних недостатньо, пауза не починається: вимкни **Автоматично визначати активну гру** й укажи її `.exe` у полі **Вручну**. Старе ручне значення зберігається при перемиканні режимів. Пауза самої гри залишається вимкненою за замовчуванням; увімкнене автовизначення саме по собі нічого не призупиняє.

Розпізнавання шляхів і процесів, відмова для неігрових програм, зміна активного вікна та GUI перевірені автоматичними тестами. **Робота з конкретним вікном і грою у Windows у Linux-хмарі не перевірена.**

## Пауза самої гри (версія 3, Windows)

1. У тому Python, яким запускається Word Lookup, установити залежності: `python -m pip install -r requirements.txt`. Для оновлення попередньо встановленої програми достатньо `python -m pip install psutil`.
2. На вкладці «Головна» знайти **Пауза гри під час пошуку (Windows)** й увімкнути **Призупиняти активну гру при OCR-пошуку**. У версії 4 автовизначення ввімкнене; для ручного режиму його можна вимкнути й указати точну назву `.exe` з диспетчера завдань. Шлях не потрібен. За замовчуванням пауза вимкнена.
3. Повернутися у вікно цієї гри та натиснути **Ctrl+Alt+R** або **Ctrl+Alt+G**. Вибрати слово. У режимі короткої паузи процес відновлюється після кадру; у режимі до закриття картки лишається на паузі до Esc/закриття або ліміту.
4. Закрити картку, натиснути **Esc** або **Ctrl+Alt+P** — процес відновлюється. Комбінацію відновлення можна змінити на вкладці «Кнопки». При конфлікті зі старою власною комбінацією нова комбінація автоматично не призначається; залишається кнопка **Відновити гру зараз**.

Діє лише на активне вікно Windows, процес якого точно відповідає вказаному `.exe`. Word Lookup не призупиняє себе, поширені системні процеси чи вже призупинений стороннім інструментом процес. Доступ до процесу може бути відхилений системою або грою — тоді режим не відкривається й показує причину. Це призупинення процесу, а не внутрішнє меню паузи гри; не кожна гра коректно підтримує такий режим. Серверний світ онлайн-гри продовжує працювати.

Вибір слова й керований курсор працюють зі знімком. Короткий режим відновлює гру після кадру; режим до закриття картки утримує паузу під час OCR і читання перекладу. Окремий процес-сторож володіє парою `suspend/resume` та перевіряє PID і час створення процесу. Він відновлює гру після закриття каналу, завершення Word Lookup або спливання ліміту (типово **60 секунд** для нового встановлення (власний збережений ліміт не змінюється), у налаштуваннях **5–300 секунд**). Сторож не залежить від циклу Tk. Перед призупиненням сторож атомарно записує PID і час створення процесу в каталог `pause-recovery` поряд із `config.json`. Якщо примусово завершити і Word Lookup, і сторожа, наступний запуск програми відновлює лише процес із тим самим PID і часом створення, коли обидва попередні власники вже завершилися. До наступного запуску гра може залишатися призупиненою; у разі відмови доступу запис зберігається для повторної спроби. Програма не змінює файли гри й не обходить її захист.

У Linux-хмарі перевірено реальні `suspend/resume` власного тестового процесу, відновлення після аварійного завершення керівного процесу, закриття каналу, тайм-аут, скасування, помилки створення накладки та захист ідентичності PID. **Призупинення конкретної Windows-гри в цій хмарі не перевірене.**

## Доповнення за демонстрацією (версія 2)

- **Дві панелі бібліотеки**: список ліворуч, повна картка праворуч. Редагуються переклад, визначення, приклад, речення та його переклад, джерело й нотатки. **Ctrl+S** зберігає зміни. При переході до іншої картки або виході програма пропонує зберегти незбережені правки. Автоматичне довантаження не замінює власний переклад і не повертає навмисно очищене визначення.
- **Слова та фрази**: ⭐ та **Ctrl+Enter** працюють і в картці перекладеного рядка або виділеного тексту. Фрази можна повторювати й експортувати так само, як слова.
- **Зображення контексту**: натисни мініатюру, щоб відкрити її в системному переглядачі; **Додати зображення…** додає або замінює зображення вибраної картки. Увімкнене захоплення контексту також працює для OCR-рядка та прямокутної області.
- **Статуси** «Нові / Вивчаю / Знаю», фільтр **Час повторити**, пошук також у власних нотатках. Позначка «Знаю» в бібліотеці виключає запис із черги належних повторень; її можна змінити назад.
- **Прогрес між запусками**: у вбудованому повторенні успішні відповіді плануються через 1, 3, 7, 14, 30 днів; помилка — через 10 хвилин. У поточному сеансі складне слово повертається в кінець набору. Є напрямки **Англійська → Переклад**, **Переклад → Англійська** та **Пропуск у реченні**. Якщо в збереженому реченні немає слова чи його початкової форми, режим пропуску показує звичайне слово. Це власний простий розклад програми; з розкладом Anki він не синхронізується.
- **Пряме передавання в Anki**: вибери записи, назву колоди й натисни **Передати в Anki**. Якщо нічого не позначено, передаються всі знайдені за поточним фільтром записи. Повторне передавання оновлює поля тієї самої нотатки, зображення й теги. Дублікат із неоднозначним зіставленням не перезаписується — показується помилка. Програма не видаляє нотатки з Anki та не запускає синхронізацію AnkiWeb. Це передавання в один бік, з Word Lookup до Anki.

Для прямого передавання встанови в настільну Anki доповнення [AnkiConnect](https://ankiweb.net/shared/info/2055492159), перезапусти Anki та залиш її відкритою на тому самому ПК. Використовується лише локальна адреса `127.0.0.1:8765`, без стороннього сервера. Встановлення AnkiConnect у твоїй Anki та живий обмін із нею в цій хмарі не перевірені. Автоматичні тести перевіряють HTTP-протокол на локальному тестовому сервері: додавання, оновлення без дублікатів і передавання JPEG. Без AnkiConnect залишається експорт у `.apkg` або `.txt`.

## Що покращено

- Картка обмежена розмірами екрана та прокручується колесом. Є **Закріпити**, **Копіювати**, **✕**. Закріплення й позиція прокручування зберігаються при довантаженні визначень. Поки курсор на картці, таймер її не закриває.
- **Esc** закриває картку й скасовує поточний пошук: запізнілі результати та помилки не відкриють її знову. Пауза теж скасовує пошук.
- Бібліотека має пошук за словом, перекладом, визначенням, контекстом і джерелом, сортування та вибір знайдених слів. **Ctrl+F** переводить фокус у пошук.
- Збережені картки відкриваються **без мережі**, разом із визначеннями, прикладами й контекстом. Довантажені поля автоматично доповнюють уже збережене слово. Відтворення аудіо за URL потребує інтернету.
- **Повторити слова**: згадати переклад → **Пробіл** → **1 / Ще раз** або **2 / Знаю**. Складне слово повертається в кінець поточного набору. Версія 2 також зберігає простий розклад майбутніх повторень.
- На вкладці «Головна» можна увімкнути **Зберігати скриншот контексту**. Для OCR-пошуку під курсором береться область до 960×480 навколо слова. Зображення записується локально лише при збереженні слова, показується під час повторення та додається до `.apkg`. При видаленні слова його зображення теж видаляється. За замовчуванням перемикач вимкнено. Для перекладу виділеного тексту скриншот не створюється.
- Атомарний запис налаштувань, обмежений кеш без спільного змінного контексту між пошуками. Ключ DeepL приховується і в журналі, і в консолі.
- Вкладки налаштувань прокручуються — нижні кнопки доступні й на невеликому екрані.

## Запуск на Windows

Потрібен Python **3.10–3.13** з Tkinter (звичайний інсталятор python.org).

Найпростіше: розпакуй архів, двічі натисни **install.bat**, потім запускай **start.bat**. Інсталятор створює `.venv`, ставить залежності, Windows Credential Manager backend і RapidOCR. Окремий Tesseract для цього не потрібен. `start.bat` пропонує встановлення автоматично, якщо середовища ще немає.

Ручний варіант:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements-ocr.txt -c requirements.lock
.venv\Scripts\python word_lookup.py
```

RapidOCR — варіант без системного Tesseract; на першому запуску він ініціалізує моделі. Альтернатива: встановити [Tesseract для Windows](https://github.com/UB-Mannheim/tesseract/wiki) й указати шлях на вкладці «Словник і OCR». У хмарі протестовано саме Tesseract. Для значка в треї необов'язково: `pip install pystray`.

Перший сценарій: натиснути **Показати приклад**, перевірити OCR, навести курсор на англійське слово й натиснути колесо миші або **Ctrl+Alt+D**. Зберегти слово через ⭐. Потім відкрити **Збережені слова → Повторити слова** або експортувати вибрані слова в Anki. **Ctrl+Enter** у картці також зберігає слово.

Для гри бажаний режим **Вікно без рамки / Borderless**. Якщо гра захоплює мишу, скористатись **Ctrl+Alt+G** (керований курсор) або **Ctrl+Alt+R** (область на стоп-кадрі). Системні хуки та накладки у Windows-іграх потрібно перевірити на своєму ПК: у Linux-хмарі це не відтворюється.

## Linux / macOS

```bash
# Debian/Ubuntu: потрібні python3-tk, python3-venv, tesseract-ocr, xclip,
# а для збірки evdev: gcc, python3-dev, linux-libc-dev.
# macOS: Python з Tkinter та brew install tesseract.
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python word_lookup.py
```

Linux потребує графічного сеансу X11; глобальні хуки й захоплення екрана на Wayland можуть бути обмежені. У macOS слід надати дозволи Accessibility, Input Monitoring і Screen Recording.

## Дані та мережа

Старі `config.json`, `saved_words.json` і `cache.json` читаються без ручного перенесення. Каталог: `%APPDATA%/WordLookup` у Windows; `~/Library/Application Support/WordLookup` у macOS; `${XDG_CONFIG_HOME:-~/.config}/WordLookup` у Linux. Скриншоти: підкаталог `media`. Для резервної копії достатньо скопіювати каталог WordLookup. `.apkg` містить зображення; `.txt` експортує лише текстові поля.

Для нових перекладів потрібен інтернет. Наявний код використовує Google Translate з резервними джерелами MyMemory, DictionaryAPI і Datamuse; DeepL необов'язковий, його ключ вводиться лише локально в налаштуваннях. Безкоштовні неофіційні джерела можуть обмежувати запити. Зображення контексту не надсилаються перекладачам — надсилається текст.

Автоматичні тести ізолюють зовнішні джерела й перевіряють локальні сценарії, справжні вікна Tk, буфер обміну, OCR та експорт. Наявність дозволеного домену в середовищі не означає перевірки якості або доступності конкретного перекладача.

## Розробка в хмарі

Виконуй команди з розпакованого каталогу проєкту. Скрипти визначають його розташування самостійно; `setup_cloud.sh` призначений для Debian-хмари з `uv` і системним Tk.

```bash
bash scripts/setup_cloud.sh
bash scripts/run_tests.sh -q
```

`setup_cloud.sh` готує Python 3.13 / Tk 8.6, залежності з `requirements.lock`, локальні Xvfb, xclip і заголовки Python без зміни системних пакетів. `requirements.lock` — універсальний фіксований набір для Linux, Windows і macOS із платформними маркерами, включно з `pywin32-ctypes` для Windows. Він містить також тестові залежності; OCR-додаток окремо описано в `requirements-ocr.txt`. Перезібрати: `uv pip compile --universal --python-version 3.10 requirements-dev.txt -o requirements.lock`.

`run_tests.sh` створює окремий віртуальний екран, якщо DISPLAY не заданий, ізолює дані й прибирає лише власний процес Xvfb. Тести перевіряють реальні вікна, прокручування, закріплення, скасування, бібліотеку, повторення, системний буфер обміну, Tesseract на зображенні, конкурентний кеш, атомарний запис і вміст Anki-пакета з медіа. Зовнішні перекладачі в тестах ізольовані; це не перевірка доступності їхніх серверів.

## Референс

З наданого відео взяті сценарії словникової картки поверх гри, речення з підсвіченням, бібліотеки, зображення контексту та карток повторення. Це розвиток вашої Tkinter-програми з цими сценаріями; точне відтворення зовнішнього вигляду й усіх функцій іншої програми не заявляється.


## Автоматичні перевірки Windows

`.github/workflows/windows-tests.yml` запускає повний pytest-набір на `windows-latest`
(Python 3.12, Tesseract). Ті самі перевірки паузи працюють лише з власним тестовим
процесом: suspend/resume, тайм-аут, аварія керівного процесу, завершення і програми,
і сторожа з наступним відновленням, відмова при іншому часі створення PID. Окремо
створюються справжні накладки Tk і перевіряється глобальний хук синтетичною
комбінацією клавіш у власному сеансі. Результати публікуються як артефакт CI.

Це не запуск Cyberpunk і не гарантія сумісності з його повноекранним режимом чи
захистом гри. Windows CI потрібно виконати на GitHub; Linux-хмара не підтверджує
результат цього workflow. У `.exe`-збірці ранній `--pause-watchdog` запускає лише
сторожа, без другого вікна програми; джерельний запуск використовує окремий
`word_lookup_pause.py`.

## Новий інтерфейс і безпечніший пошук (версія 6)

Інтерфейс за макетом «Word Lookup — новий інтерфейс»: графітові панелі, жовті акценти, бічна навігація налаштувань, дві панелі бібліотеки. У картці спочатку показано слово, транскрипцію й речення, далі переклад і значення; унизу — джерело та збереження. Усі попередні налаштування блоків, експорт, повторення й керований курсор доступні.

Якщо OCR помилився, натисни заголовок слова або **Не те слово? Виправити**, введи слово й натисни Enter. Пошук повториться без нового виділення, скриншота та паузи гри; речення, джерело й зображення залишаються. Esc у полі скасовує редагування. Невеликий локальний список виправляє відомі помилки на кшталт `changin → changing`, а таблиця неправильних форм допомагає знайти початкову форму без окремого мережевого запиту.

Речення й переклади визначень тепер кешуються у `translations.json` поряд із кешем слів. Ключ кешу враховує мову й режим перекладача, кількість записів обмежена (до 1000); однакові одночасні запити об'єднуються. Кнопка очищення видаляє обидва кеші. Усі зовнішні словникові та перекладацькі запити, включно з резервними провайдерами, проходять спільний інтервал 0,4 с. Скасований пошук не починає наступних запитів. Це зменшує навантаження, але не гарантує відсутності лімітів сторонніх сервісів.

У Windows ключ DeepL зберігається через `keyring` у Windows Credential Manager (`WordLookup.DeepL`) або, при відмові, у локальному файлі Windows DPAPI; відкритого файлового запасного сховища немає. Старий відкритий ключ мігрує під час запуску; після успішного запису налаштувань поле ключа в JSON порожнє. Без обох захищених сховищ, зокрема у Linux-хмарі, ключ працює лише до завершення сеансу. Резервні копії старих конфігурацій можуть містити старий ключ.

Код розділено на модулі паузи, сховища, Anki, OCR, UI, мережевого керування й секретів. `word_lookup.py` залишається точкою входу й сумісним API для тестів; модулі сховища/OCR/Anki/UI отримують спільний контекст через `configure`, тому конфігурація та адаптери залишаються єдиними. Помилки відновлюваних операцій записуються в журнал з маскуванням ключа; нормальне завершення порожньої черги не є помилкою.

GitHub Actions `.github/workflows/windows-tests.yml` запускає повний pytest-набір на `windows-latest`, встановлює Tesseract та перевіряє власний тестовий процес (пауза/відновлення), справжні вікна накладок і системні гарячі клавіші. Наявність workflow не означає, що Windows-прогін уже відбувся; живу гру Cyberpunk CI не запускає.

## PNG інтерфейсу

На Linux з Xvfb:

```bash
xvfb-run -a -s '-screen 0 1440x1000x24' .venv/bin/python scripts/render_screens.py --output-dir artifacts/screenshots
```

На Windows: `.venv\Scripts\python scripts\render_screens.py --output-dir artifacts/screenshots`.
Скрипт використовує тимчасові дані, локальну намальовану сцену й підготовлені результати OCR, блокує зовнішні запити та не читає Credential Manager. PNG показують справжню верстку Tk, але не є доказом роботи накладки поверх реальної гри. У GitHub Actions результати Linux зберігаються у `linux-desktop-results`; Windows-знімки мають окремі артефакти `windows-ui-segoe-tk-100pct`, `windows-ui-segoe-tk-125pct` і `windows-ui-segoe-tk-150pct`. Генеровані PNG/XML не слід додавати до Git або вихідного архіву.
