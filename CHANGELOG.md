# Зміни

## 8.5.0 — 17.11.2026

- Захист від другого екземпляра з активацією першого вікна; легкий запуск сторожа без Tk.
- Сувора перевірка конфігурації, BOM, збереження пошкодженого оригіналу, іменовані міграції.
- Версії схем бібліотеки й кешів; захист від запису поверх невідомих майбутніх форматів.
- Keychain / Secret Service на додаток до Credential Manager / DPAPI; окреме збереження API-ключів.
- Потокове читання відповідей до 2 МБ, MIME аудіо, блокування стану сесії та cooldown.
- Офіційні Google Cloud Translation і LibreTranslate; індикатор джерела перекладу; контрактні фікстури.
- Необов'язковий локальний CTranslate2 для моделей Argos, імпорт моделі, обмеження CPU, без автоматичних завантажень.
- Мережа зібрана в `wordlookup/network`; явні Settings, Library, CardCache, Providers, Ocr та Anki.
- App розділено на контролери пошуку, введення, подій, паузи та вікон; видалено configure/runtime.
- Іменовані dataclass-події інтерфейсу; сумісність старого модуля залишена лише на зовнішній межі.
- Єдиний каталог даних, стандартна ротація журналу, обробка помилок Tk і потоків.
- Локальний діагностичний ZIP: DPI, версії, обмежена часова шкала та необов'язковий OCR-знімок.
- PresentMon-процедура для вимірювання FPS; причину проблеми Mafia не оголошено встановленою.
- Перший gettext-шар, каталог статичних підписів; частковий англійський каталог для перекладачів.
- Фокус і Enter/Пробіл для виправлення заголовка; видимий фокус кнопок, контраст «Сепії».
- Експорт Anki закриває SQLite, прибирає тимчасову базу та атомарно замінює попередній пакет.
- Pyproject, PyInstaller spec, Windows EXE workflow та перевірка вбудованого OCR/Tk.
- Ruff, поступовий mypy, покриття, pip-audit, Dependabot, macOS domain CI; видалено deep-translator/bs4.
- Python 3.11–3.13; вилучено вразливі залежності старої гілки Python 3.10 та важкий Stanza/Torch-ланцюжок.
- Ліцензія оригінального коду: всі права захищено, за рішенням власника.
